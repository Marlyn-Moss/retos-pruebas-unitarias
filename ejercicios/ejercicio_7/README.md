# Ejercicio 7 · Contar vocales

**Enunciado.** Escribe `contarVocales(texto)` que cuente las vocales sin importar mayúsculas ni tildes.

**Qué practicas:** elegir casos que rompen implementaciones ingenuas: mayúsculas, tildes y textos sin coincidencias.

**Ejecuta:** `npm test -- ejercicio_7`

**Reto:** escribe `contarConsonantes(texto)`. ¿Qué pasa con los espacios y los números?
