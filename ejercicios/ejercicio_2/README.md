# Ejercicio 2 · ¿Es par?

**Enunciado.** Escribe `esPar(numero)` que devuelva `true` si el número es par y `false` si es impar.

**Qué practicas:** afirmaciones booleanas con `toBe(true)`, `toBe(false)`, `toBeTruthy` y `toBeFalsy`.

**Ejecuta:** `npm test -- ejercicio_2`

**Reto:** escribe `esImpar(numero)` reutilizando `esPar`, con sus propias pruebas.
