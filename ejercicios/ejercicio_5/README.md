# Ejercicio 5 · Convertir temperaturas

**Enunciado.** Escribe `celsiusAFahrenheit(c)` y `fahrenheitACelsius(f)`.

**Qué practicas:** valores conocidos como casos de prueba (0, 100, -40) y una prueba de "ida y vuelta" que combina las dos funciones.

**Ejecuta:** `npm test -- ejercicio_5`

**Reto:** agrega `celsiusAKelvin(c)` (K = °C + 273.15) y prueba que -273.15 °C son 0 K.
