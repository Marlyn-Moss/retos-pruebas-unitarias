# Ejercicio 12 · Cupón de descuento (kata TDD)

**Enunciado.** `aplicarDescuento(total, cupon)` aplica 10 % con RETOS10 y 20 % con RETOS20, sin importar mayúsculas. Un cupón inexistente o vacío no descuenta. El resultado se redondea a dos decimales.

**Qué practicas:** el ciclo Rojo-Verde-Refactor. Las pruebas están numeradas en el orden en que se escribieron.

**Ejecuta:** `npm test -- ejercicio_12`

**Reto TDD:** borra el contenido de la función y vuelve a construirla prueba por prueba: activa una prueba (las demás con `test.skip`), hazla pasar con el mínimo código y refactoriza.
