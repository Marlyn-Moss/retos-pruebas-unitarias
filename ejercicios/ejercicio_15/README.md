# Ejercicio 15 · Carrito de compras

**Enunciado.** La clase `Carrito` permite agregar productos (sumando la cantidad si ya estaban), quitarlos, contar unidades y calcular el total redondeado a dos decimales. No acepta cantidades de cero o menos.

**Qué practicas:** probar una clase que guarda estado y usar `beforeEach` para que cada prueba empiece con un carrito nuevo.

**Ejecuta:** `npm test -- ejercicio_15`

**Reto:** quita el `beforeEach` y crea el carrito una sola vez arriba. ¿Qué pruebas fallan y por qué?
