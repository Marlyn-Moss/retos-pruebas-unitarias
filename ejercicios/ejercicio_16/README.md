# Ejercicio 16 · Filtrar y ordenar productos

**Enunciado.** Escribe `filtrarPorPrecioMaximo`, `ordenarPorPrecio` (ascendente o descendente) y `nombresDisponibles` (solo productos con stock). Ninguna debe modificar la lista original.

**Qué practicas:** comparar arreglos con `toEqual`, negar afirmaciones con `.not` y comprobar que una función no tiene efectos secundarios.

**Ejecuta:** `npm test -- ejercicio_16`

**Reto:** en `ordenarPorPrecio`, quita la copia y ordena `productos` directamente. ¿Qué prueba lo detecta? Es el mismo tipo de defecto que el ordenamiento de Sauce Demo.
