# Ejercicio 6 · Invertir un texto

**Enunciado.** Escribe `invertirTexto(texto)` que devuelva el texto al revés. Si no recibe un texto, debe lanzar un `TypeError`.

**Qué practicas:** casos borde (texto vacío, una letra, caracteres especiales) y `toThrow(TipoDeError)`.

**Ejecuta:** `npm test -- ejercicio_6`

**Reto:** agrega `invertirPalabras('hola mundo')` que devuelva `'mundo hola'`.
