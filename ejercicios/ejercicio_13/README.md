# Ejercicio 13 · FizzBuzz

**Enunciado.** `fizzBuzz(n)` devuelve "Fizz" si n es múltiplo de 3, "Buzz" si es múltiplo de 5, "FizzBuzz" si es de ambos y el número como texto en otro caso. `generarFizzBuzz(hasta)` devuelve la lista del 1 al número indicado.

**Qué practicas:** la kata más usada para aprender TDD, y la diferencia entre `toBe` (valores) y `toEqual` (contenido de arreglos).

**Ejecuta:** `npm test -- ejercicio_13`

**Reto:** agrega la regla "Bazz" para múltiplos de 7, empezando por la prueba.
