# Ejercicio 8 · ¿Es palíndromo?

**Enunciado.** Escribe `esPalindromo(texto)` que diga si un texto se lee igual al derecho y al revés, ignorando espacios, mayúsculas, tildes y signos. Un texto vacío no es palíndromo.

**Qué practicas:** pruebas que van de lo simple a lo complejo; cada una agrega una regla nueva.

**Ejecuta:** `npm test -- ejercicio_8`

**Reto:** prueba con números como `'12321'` y con una frase que tenga la letra ñ.
