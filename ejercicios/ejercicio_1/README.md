# Ejercicio 1 · Sumar dos números

**Enunciado.** Escribe la función `sumar(a, b)` que devuelva la suma de dos números.

**Qué practicas:** la estructura de una prueba (Arrange, Act, Assert), `describe`, `test`, `toBe` y `toBeCloseTo`.

**Ejecuta:** `npm test -- ejercicio_1`

**Reto:** agrega una prueba que sume tres números grandes, por ejemplo 1 000 000 + 2 500 000.
